Interactive Power BI dashboard for analyzing Indian wedding and event data, including budget, cost, guests, venues, vendors, and satisfaction.

**1. Project Overview**
An interactive Power BI dashboard developed to analyze Indian wedding and event data, including events, budgets, costs, guests, venues, and vendors.

**2. Objective**
The objective of this project is to analyze event data, identify cost and spending patterns, understand guest and event trends, and generate meaningful insights through interactive dashboards.

**3. Tools Used**
Power BI
Power Query
DAX
Data Modeling

**5. Dashboard Pages**
📊 Executive Overview
Provides an overall summary of events, budgets, costs, satisfaction, and event trends.

💰 Budget & Cost Analysis
Analyzes budget vs. actual costs, cost trends, budget variance, and cost distribution.

👥 Guest & Event Analysis
Analyzes guest count, event size, satisfaction, event types, and event trends.

🏛️ Venue & Vendor Analysis
Analyzes venue types, event costs by venue, vendor categories, and vendor ratings.

**6. Key Insights**
600 total events analyzed.
₹381.64M total planned budget.
₹374.00M total actual cost.
₹7.65M positive budget variance, indicating overall spending was below the planned budget.
174K total guests across all events.
4.11/5 average guest satisfaction.
2.15K average cost per guest.
2.90K average event cost.
